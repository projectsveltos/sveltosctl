# Third-Party License Notices

`sveltosctl` is distributed as a standalone binary/CLI, independently of the main Sveltos Helm
chart (see `helm-charts/THIRD_PARTY_LICENSES.md` for that bundle's notices). This document lists
every third-party license found in `sveltosctl`'s own dependency tree, generated by scanning its
actual build target with [`google/go-licenses`](https://github.com/google/go-licenses):

```bash
go install github.com/google/go-licenses/v2@latest
go-licenses report ./cmd/...
```

First-party `github.com/projectsveltos/*` packages are excluded (Sveltos's own code, not
third-party).
